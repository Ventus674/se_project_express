# Project Name

WTWR application

# Project description

This is the back-end part of the project and is focused on creating a server for the "What to wear" application. It focuses on the back end of it and creates a database to store all the information rather than losing it upon reloading the application. This is a stepping stone to creating a full server with an API and user authorization.

# technology and techniques used

The backend runs on Node.js with Express and MongoDB and is managed by PM2 for stability.I built this on VS code using purely Javascript. Other programs to check my work including Postman and GitHub Actions

## Running the Project

`npm run start` — to launch the server

`npm run dev` — to launch the server with the hot reload feature
